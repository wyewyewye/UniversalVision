# UniversalVision
一个万能的，用于浏览本地多媒体（文件/设备）、进行视频会议、推拉流直播的轻量级应用。

A lightweight universal application for browsing local multimedia(files/devices), RTC, pushing/pulling stream(live).

# Environment
Base on: C++17, vs2022
